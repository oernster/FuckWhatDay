Frequently avoided questions

Why?

WhatDay already solved this problem sensibly. Someone had to solve it the other way, so that the sensible way would have something to be compared with.

Does it know what day it is today?

No. It has no clock and never will. You tell it a date; it tells you the day. If you need today's date, try a window.

Is Python secretly doing the real work?

No. Python generates the Brainfuck, tests it and runs it. It never sees a date while generating it; the calculation happens only when the Brainfuck runs. A structural test fails if the generator so much as imports the datetime module. The demo proves the point another way: it runs on JavaScript that has never heard of Tuesday.

Is it fast?

It executes up to 567,392 instructions to answer a question your phone answers with none. On the other hand, the exe still finishes in about 10 ms, so it is fast in the way that a very large number of very small mistakes can be fast.

Does it support 2100?

No. The supported range is 1900 to 2099. 2100 is not a leap year either, so the two of you have more in common than you think.

Can I use it in production?

You can. We cannot stop you. Every supported date has been tested, so it would at least be correct, which is more than can be said for the decision.

What happens if I type a hyphen?

INVALID. The format is YYYYMMDD. The program reads eight digits and a terminator; if anything else turns up it stops reading and says so. Try it in the demo; it is quite satisfying.

Was this a good use of time?

The README lists "make sensible use of engineering time" under "What it does not do". We stand by the README.
